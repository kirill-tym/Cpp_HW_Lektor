Запуск из корня репозитория:

mkdir -p build
c++ -std=c++17 task{i}/main.cpp -o build/task{i}
./build/task{i}

Вместо i номер задачки подставить надо

Ввод через консоль

Четвёртая задача выглядит так:

Программа хранит запасы на складе и выполняет записи журнала

Ввод:

1. Число зон.
2. Для каждой зоны — число стеллажей, затем количество ячеек на каждом стеллаже.
3. Число записей журнала.
4. Записи set {номер зоны} {номер стеллажа} {номер ячейки} {количество} или note {слово (запись)}.

Индексы начинаются с нуля и должны быть в пределах склада. set задаёт количество товара в ячейке. note выводит заметку, т.е. слово без пробелов длиной до 100 символов

Пример ввода:

```text
1
1 2
2
set 0 0 1 5
note test
```

Вывод:

```text
note: test
zone 0: 5
```
